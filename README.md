## 3. Структуры

<!-- structures.begin -->

### 3.1 CreateMyItemRequest

Запрос на создание элемента

| Поле | Тип    | Описание     |
|------|--------|--------------|
| name | string | имя элемента |

### 3.2 DeleteMyItemRequest

Запрос на удаление элемента

| Поле | Тип    | Описание                                |
|------|--------|-----------------------------------------|
| id   | string | уникальный идентификатор в формате UUID |

### 3.3 GetMyItemRequest

Запрос на получение элемента

| Поле | Тип    | Описание                                |
|------|--------|-----------------------------------------|
| id   | string | уникальный идентификатор в формате UUID |

### 3.4 ListMyItemsRequest

Запрос на получение списка элементов

| Поле        | Тип   | Описание        |
|-------------|-------|-----------------|
| page_size   | int32 | размер страницы |
| page_number | int32 | номер страницы  |

### 3.5 ListMyItemsResponse

Список элементов

| Поле             | Тип      | Описание                     |
|------------------|----------|------------------------------|
| my_items         | []MyItem | список элементов на странице |
| next_page_number | int32    | номер следующей страницы     |

### 3.6 MyItem

Описание элемента

| Поле       | Тип       | Описание                                |
|------------|-----------|-----------------------------------------|
| id         | string    | уникальный идентификатор в формате UUID |
| name       | string    | имя элемента                            |
| created_at | Timestamp | время создания элемента                 |
| updated_at | Timestamp | время последнего изменения элемента     |

### 3.7 UpdateMyItemRequest

Запрос на обновление элемента

| Поле | Тип    | Описание                                |
|------|--------|-----------------------------------------|
| id   | string | уникальный идентификатор в формате UUID |
| name | string | имя элемента                            |

<!-- structures.end -->

## 6. Запросы REST

<!-- rest.begin -->

|   | Ручка                        | Запрос                                  | Успех                                        | Неудача | Описание                          |
|---|------------------------------|-----------------------------------------|----------------------------------------------|---------|-----------------------------------|
| 1 | DELETE /api/v1/my-items/{id} | draftproject.api.v1.DeleteMyItemRequest | 200, google.protobuf.Empty                   | 500     | Удаление существующего элемента   |
| 2 | GET /api/v1/my-items         | draftproject.api.v1.ListMyItemsRequest  | 200, draftproject.api.v1.ListMyItemsResponse | 500     | Получение списка элементов        |
| 3 | GET /api/v1/my-items/{id}    | draftproject.api.v1.GetMyItemRequest    | 200, draftproject.api.v1.MyItem              | 500     | Получение существующего элемента  |
| 4 | PATCH /api/v1/my-items/{id}  | draftproject.api.v1.UpdateMyItemRequest | 200, draftproject.api.v1.MyItem              | 500     | Обновление существующего элемента |
| 5 | POST /api/v1/my-items        | draftproject.api.v1.CreateMyItemRequest | 200, draftproject.api.v1.MyItem              | 500     | Создание нового элемента          |

## 9. Sequence-диаграмма

Диаграммы в формате PlantUML, которые позволяют лучше понять работу внутренней логики сервиса. Также здесь допускается
размещать диаграммы, в которых данный сервис является инициатором описываемого процесса. Но если сервис является звеном
в цепочке вызовов при межсервисном взаимодействии, то скорее всего диаграмму нужно публиковать в архитектурном документе
